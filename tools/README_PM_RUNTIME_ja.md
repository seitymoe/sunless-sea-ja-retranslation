# 実機P0証拠の取得手順

ゲーム本体・Steam Cloud・セーブ・DLLを書き換えない。QEffectOnEnter例外と商店の入力不具合は、ログ件数だけで修正済みとしない。

- P0 #1: `BUY £5` と `SELL £1` のクリック直前・直後・再描画後に Echo・商品数・クリック時刻を、ゲームを所有するテスト環境で記録する。
- P0 #2: 南方群島の QEffectOnEnter を原本・修正版で同一セーブの安全な複製から比較する。
- 取得したログは公開Issueにそのまま添付せず、個人情報やセーブ内容を除いた診断結果・SHAのみ共有する。
- エラーや未確認が一つでも残る場合は公開テスト版のまま維持する。
